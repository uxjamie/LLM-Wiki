# raw/

Sources go here: articles, transcripts, notes, documents, exports, clipped web pages. The AI reads them and never edits them. The wiki pages built from them live in `wiki/`.

- **Name new files with the date and a topic:** `2026-10-16-onboarding-notes.md`.
- **Images and attachments** go in `assets/`.
- **A thought shared in chat** gets saved here as a file first, then ingested.
- **A transcript** gets a short note beside it listing names and terms the speech-to-text got wrong, named after the transcript: `2026-10-16-team-sync-misrenderings.md`. Quote only after checking it.
- **Subfolders are fine** when a batch of sources belongs together.

Existing files here are never edited. To correct one, add a new file that says what changed.
