# Open Items Archive

Where items leave [[open-items]], so that file stays short. Text moves word for word, newest first in each section. Session start does not read this page. To revive a shelved thread, move it back to open-items. The rule is in the rules file, *Session protocol*.

## Done

Each entry: the date it closed, one line on what closed it, then the item as it read.

## Shelved

Grouped by thread, so each can be revived intact.

## Retired decisions

Superseded, or folded into the rules file, an adapter or a page. Each names where the rule lives now.
